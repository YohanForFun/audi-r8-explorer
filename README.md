# Audi R8 结构探索工作台

一个可在浏览器中自由交互的 Audi R8（二代风格）3D 结构示意模型：楔形车身、侧刀、六边形单框格栅、双座驾驶舱、中置 5.2L V10、7 速 S tronic、quattro 传动、冷却与排气、铝 + CFRP 空间框架、四轮双叉臂悬挂与制动。

> 说明：整车由 three.js 程序化生成（放样曲面 + 参数化零件），属于**结构示意**，并非奥迪原厂 CAD 数据，尺寸与布置为近似表达。

## 运行方式（本地）

本项目是纯静态网页，**不能直接双击 index.html 打开**（浏览器会拦截 ES 模块），需要用本地服务器：

1. 解压压缩包，进入包含 `index.html` 的文件夹；
2. 在该文件夹打开终端，运行：

   ```bash
   python -m http.server 8000
   ```
   （Windows 上也可用 `py -m http.server 8000`）
3. 用 Chrome / Edge / Safari 打开 <http://localhost:8000>

所有依赖（three.js r187 及其扩展）都已随包附带在 `vendor/` 目录，**无需联网**即可运行。

## 在线部署

文件夹可原样上传到任意静态托管：Cloudflare Pages、GitHub Pages、Vercel、Netlify、对象存储静态网站等。以 Cloudflare Pages 为例：新建项目 → 选择“直接上传” → 上传本文件夹即可，无需构建命令。

## 交互说明

| 操作 | 说明 |
|---|---|
| 拖动 / 滚轮 | 旋转、缩放视角 |
| 点击 3D 部件 | 选中并高亮该部件，弹出所属结构的讲解卡片 |
| 左侧「结构导航」 | 6 大类：车身与空气动力、双座驾驶舱、动力与传动、冷却与排气、车架与底盘、悬挂与制动；点击后镜头聚焦并自动降低车身透明度 |
| 讲解卡片 | 「关闭讲解」/「查看讲解」/「聚焦这一结构」 |
| 打开车门 / 打开前后盖 | 车门前铰链外摆；前备箱盖后铰链上翻；发动机玻璃盖前铰链上翻 |
| 车身可见度 | 0%（仅内部）↔ 100%（完整车身） |
| 结构展开 | 组装 ↔ 分离（爆炸视图） |
| 模型表现 | 原色 / 白模 / 线框（线框按系统着色） |
| 车漆色块 | 阿拉蓝、铃鹿灰、冰川白、维加斯黄、探戈红 |
| 右侧工具条 | 放大、缩小、重置模型、自动旋转 |
| 底部图标 | 切换展厅灯光（明亮展厅 / 夜间聚光）、显示结构标注 |
| 顶部按钮 | 下载模型（把当前装配体导出为 GLB）、全屏显示 |

## 文件结构

```
index.html        页面与界面
css/app.css       样式
js/body.js        车身放样曲面（截面插值 + 超椭圆收口 + 轮拱裁切）
js/car.js         车身面板、灯组、格栅、内部结构、悬挂、车轮等全部零件
js/tex.js         程序化纹理（碳纤维、蜂窝格栅、virtual cockpit、制动盘）
js/data.js        结构分类与讲解文案
js/main.js        场景、灯光、展台反射、交互、材质模式、爆炸视图、GLB 导出
vendor/three/     three.js r187（MIT License）
```
